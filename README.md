Cvars:  
Rotative C4_voice "3" ----> 1 = english Male, 2 = english Femele, 3 = Spanish  
amx_showc4timer <0|1|3> - Off | T's only | CT's only | ALL (Default: 3)  
amx_showc4flash <0|1> - Sprite flashing (Default: 1)  
amx_showc4sprite <0|1> - Choose from 2 sprites (Default: 1)  
amx_showc4msg <0|1> - Shows a hud message about the timer (Default: 1)  
amx_soundc4 <0|1> -Sound Exploting (Default: 1)
